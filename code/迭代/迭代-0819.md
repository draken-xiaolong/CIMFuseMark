# CIMFuseMark 实验迭代计划（0819）

## 一、迭代目标

本轮迭代以形成可投稿的 CIMFuseMark 实验体系为目标。实验数据继续限定为日本国土交通省 Project PLATEAU，不引入美国、香港或其他国家和地区的数据。实验设计应同时验证：

1. 不同日本城市之间的泛化能力；
2. 攻击后同源指纹的稳定性；
3. 不同 CIM 之间的指纹唯一性；
4. CityGML/CIM 特有编辑下的鲁棒性；
5. 语义特征、图结构和各训练损失的真实贡献；
6. 模型的计算成本、可扩展性和统计稳定性。

迭代过程中不能只追求攻击后的平均相似度。所有主要实验应联合报告同源相似度、异源分布、ROC-AUC、EER、FAR、FRR 和固定阈值认证结果。

### P0-1 扩大日本 PLATEAU 数据规模并建立跨城市划分

#### 目标

解决当前数据只有东京三个行政区、31 个 tile、11 个测试模型的问题，建立真正的跨城市泛化实验。

#### 实施方案

- 数据仍全部来自 Project PLATEAU；
- 保留东京部分区域作为训练数据；
- 从横滨、川崎等城市中选择验证数据；
- 从大阪、札幌、京都、福冈等城市中选择测试数据；
- 训练、验证和测试之间不得共享城市、网格或建筑对象；
- 每个 tile 的建筑数量、节点数量和采样规则保持一致；
- 优先选择包含 WallSurface、RoofSurface、GroundSurface、BuildingPart 等语义对象的 LoD2 数据。

- 数据审计 JSON；
- 数据规模统计表；

#### 完成判据

- 所有文件可以重新下载、解析和构图；
- 数据审计无解析失败；
- 论文主实验不再依赖原来的 11 个新宿测试 tile。

### P0-3 建立严格的验证集阈值协议

#### 目标

#### 实施方案

2. 阈值确定后冻结，不因测试攻击类型或强度重新标定；
3. 在完全未见测试城市上报告 FAR、FRR、TAR 和 ROC-AUC；
4. 增加 FAR=1\% 和 FAR=5\% 时的 TAR；
5. 开放集认证使用独立背景城市完成阈值校准；
6. 明确区分闭集登记认证和开放集拒识。

#### 预期输出

- 阈值校准配置和脚本；
- 验证集阈值审计 JSON；
- 测试集固定阈值结果表；
- ROC 和 FAR--FRR 曲线；
- 闭集与开放集协议示意图。

#### 完成判据

- 测试集不参与阈值选择；
- 论文主表同时包含 AUC/EER 和固定阈值 FAR/FRR；
- 不再使用测试集自身的异源 $q_{.95}$ 作为最终认证阈值。

### P0-4 补充 CityGML/CIM 特有攻击

#### 目标

突出 CIMFuseMark 与普通三维网格或点云零水印的区别，验证模型是否真正利用 CIM 的语义、层级和编码结构。

#### 必做攻击

1. **跨 LoD 攻击**：LoD2 降级为 LoD1；
2. **格式往返攻击**：CityGML 转换为 CityJSON 后再转换回 CityGML；
3. **层级扁平化**：删除或重组 Building--Surface 层级；
4. **关系删除/重连**：改变 bounded-by、part-of 或空间邻近边；
5. **语义标签修改**：WallSurface、RoofSurface、GroundSurface 标签删除或互换；
6. **建筑增量更新**：增加建筑、BuildingPart 或语义表面；
7. **连续空间裁剪**：删除一个完整地理区域，而不是随机删除对象；
8. **XML 重排和 ID 重命名**：重排 cityObjectMember、重写对象 ID；
9. **坐标单位或坐标系转换**：在可逆转换后重新提取指纹。

#### 评价要求

- 攻击必须作用于真实文件并重新解析构图；
- 记录攻击前后节点数、边数、对象数和文件有效性；
- 跨 LoD 和格式转换应尽量使用同一对象的配对数据；
- 无法构图的结果按认证失败计入，不得静默删除；
- 分别报告语义损伤比例和几何损伤比例。

#### 预期输出

- CIM 专用攻击模块和单元测试；
- 攻击有效性审计；
- 跨 LoD、跨编码和层级攻击结果表；
- 典型攻击前后 CityGML/语义图可视化。

#### 完成判据

- 至少完成跨 LoD、格式往返和层级关系编辑三类核心攻击；
- 能够说明 CIMFuseMark 是否真正优于只使用点坐标的模型；
- 论文攻击协议体现 CIM 特色，而不是普通三维网格攻击的简单迁移。

### P0-5 在扩大数据上统一比较 Base、Separation 和 Personalized

#### 预期输出

## 三、P1：强烈建议完成的机制与统计实验

> **完成状态（2026-08-19）**：P1-1 至 P1-5 已全部执行并通过 fail-closed 完整性校验。实验矩阵共24个条目：21个新模型均独立训练800轮，完整模型、无separation和no-edge三项复用P0同协议检查点。每个条目均在64个测试模型上评价10类核心攻击、13个强度点，并使用独立验证城市冻结开放集阈值。三随机种子的核心攻击平均AUC、EER和TAR@FAR≤5% 为 $0.899\pm0.010$、$13.59\%\pm0.96\%$和 $0.654\pm0.023$；已完成2,000次分层bootstrap和与最优人工基线的配对Wilcoxon检验。完整typed图的固定阈值TAR高于所有图变体，但平均AUC不占优；几何+层级深度优于完整特征。因此论文已按实测结果收紧图传播和语义特征主张，不宣称其全面显著有效。效率审计显示R-GCN含234,849个参数，单图纯推理0.734 ms，训练峰值显存18.82 GiB；10个未缓存PLATEAU源文件共11.730 GiB，在3文件并发aria2协议下下载耗时1,146.93 s。原始结果和检查点位于 `/Volumes/SANDISK-ELE/CIMFuseMark/CIMFuseMarkData/results/p1` 与 `checkpoints/p1`，生成表图位于 `docs/p1_results_generated`。

## 五、P3：当前不优先或不建议照搬的内容

### P3-1 区块链登记实验暂不作为主线

LiteGeoFuseMark 包含 Sepolia 登记、Gas 消耗和查询延迟实验。CIMFuseMark 当前核心贡献是学习式 CIM 零水印和语义图特征提取，暂时不需要照搬区块链实验。

只有在论文明确将“可追溯版权登记系统”列为主要贡献时，才考虑增加：

- 链上内容标识登记；
- 版本路径查询；
- 查询负例；
- Gas 和延迟统计。

否则区块链内容会分散论文主线，并增加系统实验工作量。

### P3-2 不机械复制 LiteGeoFuseMark 的 92 种攻击

CIMFuseMark 不需要为了数量完全复刻二维矢量数据的 92 种配置。应优先保证攻击具有明确的三维 CIM 含义，并覆盖：

- 几何不变量；
- 属性编辑；
- 对象增删；
- 空间裁剪；
- 语义关系破坏；
- 跨 LoD；
- 跨编码；
- 复合和顺序攻击。

攻击数量不是核心，攻击定义的真实性、可复现性和 CIM 针对性更重要。

### P3-3 暂不继续单独优化 80\% 删除相似度

80\% 结构删除后，剩余内容可能已经不足以代表原始 CIM。继续单独提高此时的同源相似度，可能导致模型忽略身份相关结构并加剧异源碰撞。

后续优化应优先关注：

- 固定阈值认证性能；
- 异源 $q_{.95}$ 和最大值；
- 开放集 FAR；
- 20\%--40\% 真实编辑下的稳定性；
- 删除后剩余信息量与“拒绝认证”机制。

## 七、论文结论启用条件

### 可以使用的结论

完成扩大跨城市实验、统一 baseline、固定阈值评价和 CIM 特有攻击后，可以支持：

> CIMFuseMark 利用学习式语义对象表示，在日本 PLATEAU 的跨城市 CityGML 数据上实现了对多类几何、属性、结构与编码攻击的非侵入式版权认证，并在鲁棒性与异源唯一性的联合指标上优于传统人工特征基线。

### 需要额外证据才能使用的结论

以下表述必须满足对应条件后才能写入摘要和贡献：

- “多关系 GNN 显著有效”：完整 typed 模型必须稳定优于 no-edge 和 untyped；
- “具备跨城市泛化能力”：测试集必须包含训练未见的日本城市；
- “具备开放集认证能力”：必须由独立验证城市确定阈值，并在未登记测试城市上控制 FAR；
- “抵抗 80\% 结构删除”：必须在固定验证阈值下保持可接受 FAR/FRR，而不能只看平均相似度；
- “首次将图神经网络用于 CIM 零水印”：必须完成系统文献检索后才能最终确认。

### 当前不应使用的结论

- 不能把 8 个登记对象的闭集 AUC 1.000 外推为开放世界性能；
- 不能因为模型采用 R-GCN 就直接声称关系传播带来提升；
- 不能把攻击后高相似度等同于可靠认证；
- 不能将 60\%--80\% 结构删除描述为当前稳定工作区间。

## 八、P2 编码器、增强特征与轻量化探索（已完成）

本轮固定 G8+D 和 seed 2026，统一比较 R-GCN、GCN、GraphSAGE、GAT 与关系感知 GAT；模型选择以独立验证区校准的开放集 TAR@FAR=5\% 为主，AUC、EER、异源尾部和参数量为辅。

- 全宽 R-GCN 仍是主模型：234,849 参数，AUC 0.9097，开放集 TAR 0.7115。
- 普通 GAT 是轻量折中：179,937 参数，AUC 0.9087，开放集 TAR 0.6911；没有超过 R-GCN。
- 关系感知 GAT 没有产生净增益，不作为后续主编码器。
- R-GCN 64/192 是轻量候选：117,057 参数，保留主模型 99.5\% 的开放集 TAR（0.7079），参数减少 50.2\%。
- R-GCN 64/128 仅 84,033 参数，虽小于 LiteGeoFuseMark 的 87,857 参数，但开放集 TAR 降至 0.5036，拒绝采用。
- G8+D+C、G8+D+C+S 和 G8+D+C+S+F 已按顺序完成。频域版本取得最高 AUC 0.9203 和最低 EER 0.1149，但开放集 TAR 只有 0.6238，不能替换 G8+D 主配置。

因此论文建议同时报告：

1. `CIMFuseMark-RGCN`：效果优先的主模型；
2. `CIMFuseMark-Lite`：64/192 的轻量模型；
3. GAT 和频域结果作为负结果/权衡消融，避免宣称注意力或更多特征必然更优。

完整表格见 `docs/p2_results_generated/P2_EXPLORATION_REPORT.md`，原始 JSON 和检查点归档于外置数据目录 `results/p2`。

### P2 个性化补充实验（CIMFuseMark-Lite）

在 Lite 64/192、seed 2026 上比较 Base、只优化投影和部分编码器微调。部分微调从投影个性化检查点初始化，冻结输入层和第一层 R-GCN，只更新第二层 R-GCN、池化、readout 与投影，并使用登记模型的合成攻击视图和验证城市背景负样本。

- Base：异源 q95 0.7322，AUC 0.8929，EER 0.1338，开放集 TAR 0.7079；
- Projection-only：异源 q95 0.5586，AUC 0.9270，EER 0.0969，开放集 TAR 0.6683；
- Partial fine-tuning：异源 q95 0.5588，AUC 0.9314，EER 0.0838，开放集 TAR 0.6947。

部分编码器微调保留了投影个性化的尾部唯一性，并恢复了大部分 Base 固定阈值 TAR。当前只完成单随机种子，正式启用前仍需 seed 2027/2028 复验。Base 仍作为不接触登记测试身份的通用参考；个性化版本属于登记后、传导式认证方案，论文中必须分开报告。
