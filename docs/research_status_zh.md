# CIM / CityGML 零水印研究现状（探索稿）

更新日期：2026-08-08。

## 结论

不能声称“首次提出 CIM、CityGML 或 BIM 零水印”。至少已有以下直接先行研究：

1. Jiang 与 Kim 在 2018 年发表 *Zero Watermarking Scheme for CityGML*。该方法从 CityGML 提取点和拓扑信息，主要利用顶点范数的全局几何性质构造零水印，并测试平移、旋转、统一缩放、顶点重排、简化、平滑和噪声攻击。
   - 原文：https://www.jatit.org/volumes/Vol96No22/13Vol96No22.pdf
2. Zhou、Ren、Zhu 与 Zhou 在 2024 年发表 BIM 数据零水印方法。该方法按照构件相对基点的距离进行空间分区，以各分区构件范数偏度的符号构造二值特征，测试平移、旋转、构件删除、构件增加及格式转换。
   - DOI：https://doi.org/10.1080/19475683.2023.2298979
   - DOAJ：https://doaj.org/article/5d2d8be04beb4dbfb6e86bbf8d66aacf
3. 倾斜摄影三维模型已有嵌入式、盲水印、可逆水印及零水印相关研究。例如 2018 年工作利用垂直方向稳定性和相邻点高差嵌入水印。
   - DOI：https://doi.org/10.12082/dqxxkx.2018.180011

## 仍可能成立的研究空档

现有 CityGML 零水印工作主要将模型视为点云或全局几何统计对象。CityGML 的核心优势——对象类别、空间边界、包含层级、对象关系、多 LoD 与不同编码——尚未在公开先行方法中得到系统联合建模。CIMFuseMark 更合适的定位是：

> 面向语义三维城市模型的几何—语义—层级/拓扑融合零水印，并重点研究跨 LoD、跨编码一致性及严格的异源碰撞控制。

候选创新问题包括：

- CityGML 3.0 多类型对象的异构关系图表示；
- 几何、对象语义、层级路径和关系结构的联合指纹；
- CityGML GML、CityJSON 及可能的 IFC 映射之间的跨编码认证；
- LoD 降级、局部城市更新、构件增删和对象重组下的一致性；
- 在独立模型上报告 ROC、AUC、EER、固定 FPR 下的召回率和异源相似度尾部；
- 全局版权认证与局部篡改定位的层次化零水印。

## 当前 v0.2 给出的证据

当前基准仅用于方向筛选：14 个 OGC 示例文件产生 98 个同源攻击对和 88 个不同家族对。简单不变量指纹取得较好的刚体变换鲁棒性，但仍观察到异源假接受，并且某些相关跨版本/LoD 文件相似度很低。这两类失败分别支持“唯一性优化”和“跨 LoD 一致性学习”作为下一阶段核心问题。
