# v0.9 日本 PLATEAU 扩大实验

## 实验目的

本轮只使用日本国土交通省 Project PLATEAU 的 CityGML 数据，检验 CIMFuseMark 在真实、富语义 LoD2 城市模型上的跨行政区泛化能力。编码器训练、模型选择和最终测试按行政区隔离，避免同一区域建筑泄漏到不同划分。

## 数据与划分

数据由 `code/configs/plateau_expanded.json` 固定到 2025 年三个东京行政区的三个网格。预处理只保留至少包含三个语义边界面的 Building，并按 8 栋建筑生成一个 CIM tile。

| 划分 | 行政区 | 网格代码 | tile | 建筑 |
|---|---|---|---:|---:|
| Train | 千代田区 | 53394519 | 12 | 96 |
| Validation | 港区 | 53393640 | 8 | 64 |
| Test | 新宿区 | 53394517 | 11 | 81 |

总计 31 个 tile、241 栋建筑和 11,359 个语义边界面，其中包括 WallSurface、RoofSurface、GroundSurface 和少量 BuildingInstallation。测试集 11 个 tile 产生 55 个异源负样本对。

## 训练协议

使用完整类型关系的 R-GCN 和 1024-bit 指纹。每个训练 CIM 同时编码干净视图及三个攻击视图，采用多正样本对比损失、软比特稳定性、量化/平衡、尾部鲁棒性和异源比特分离损失。对象删除课程学习最高到 60%，80% 仅用于压力测试。随机种子为 2026，在 NVIDIA RTX 4090 上训练 800 轮。

模型摘要为 `23f6bd27c9b2a358`。测试集干净异源相似度均值为 0.6058，q95 为 0.8422，最大值为 0.9004。下面的 FRR 固定使用该异源 q95 阈值，不随攻击强度重新标定。

## 结论

扩大测试集后，刚体旋转与属性缺失仍表现出稳定的跨区域鲁棒性；10% 建筑删除和 10% 表面删除也达到接近完美的认证效果。40% 建筑删除仍有较高 AUC，但固定阈值下已有 27.27% 的拒真率。大规模对象删除、表面删除和顺序组合攻击会破坏身份信息，当前方法不能宣称可靠抵抗 60%--80% 结构删除。

与原 8-tile 小实验相比，本轮更清楚地暴露了异源指纹尾部偏高的问题。下一步不宜继续单独追求攻击后相似度，而应扩大到更多日本城市和网格，并联合优化异源 q95、固定阈值 FRR 和多随机种子方差。

## 复现

```bash
PYTHONPATH=code python3 code/prepare_plateau_dataset.py \
  --config code/configs/plateau_expanded.json \
  --manifest-name plateau_expanded_manifest.json \
  --output-subdir plateau_expanded_tiles

PYTHONPATH=code python3 code/train_robust_contrastive.py \
  --manifest code/data/plateau_expanded_manifest.json \
  --device cuda --output-prefix rgcn_plateau_japan_expanded

PYTHONPATH=code python3 code/evaluate_robustness_curves.py \
  --manifest code/data/plateau_expanded_manifest.json \
  --checkpoint code/results/rgcn_plateau_japan_expanded.pt \
  --split test --device cuda \
  --output code/results/plateau_japan_expanded_curves.json
```

下载缓存、生成的 CityGML tile、模型检查点和逐样本结果默认不进入 Git；数据 URL、年份、网格代码和采样参数均已版本化。
