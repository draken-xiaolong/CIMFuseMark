# v0.3 CityGML 多关系图与 R-GCN 原型

## 图表示

图构建器位于 `code/cimfusemark/citygml_graph.py`。它从 CityGML XML 中识别语义对象，并构造以下信息：

- 节点：Building、BuildingPart、BuildingRoom、BuildingUnit、Storey、各类 BoundarySurface、Road、Bridge、TrafficSpace 等；
- 层级边：contains、bounded_by 和反向 part_of；
- 引用边：解析可定位的 XLink，并添加反向关系；
- 空间边：根据对象聚合几何的质心构建有向近邻关系；
- 节点特征：点数、相对模型中心的径向位置、协方差特征值比例、径向分布、层级深度、属性数量、边界角色及稳定类型哈希。

几何坐标归属给最近的语义祖先对象，再沿对象层级向上聚合。该设计保留对象结构，同时避免在每一级无控制地重复读取同一坐标。

## XML 级攻击

`code/cimfusemark/xml_attacks.py` 直接修改完整 XML 树并写出新的 GML 文件，随后重新解析构图：

- 三维平移、统一缩放、绕 Z 轴旋转；
- 坐标量化；
- 对象顺序重排；
- 属性元素删除；
- 语义对象子树删除。

这比 v0.2 的“修改最终语义计数”更接近真实数据操作，但尚未实现严格的 LoD 降级和 CityGML/CityJSON 转换。

## 无训练图基线

`graph_baseline.py` 对节点类型、关系类型、节点特征分布和度统计进行排列不变汇总，再通过带密钥固定随机投影生成二值指纹。

在全部 14 个样例上，相比 v0.2：

- 异源 q95：0.953 降至 0.936；
- 跨版本最低相似度：0.551 提升至 0.762；
- 同源 q05：保持在约 0.980；
- 极小图在对象删除下仍然脆弱，例如 2 节点模型删除 1 个节点后为 0.715。

## R-GCN 原型

`rgcn.py` 使用纯 PyTorch 实现两层关系图卷积，并使用 mean、max 和 attention 三路池化生成 128-D 图级表示。固定带密钥投影将表示转换为 256-bit 指纹。

训练目标包括：

- 原始图与攻击图的一致性；
- 同一家族不同版本的一致性；
- 不同家族图表示的间隔约束；
- 二值位平衡约束。

训练、验证和测试按照模型家族隔离。当前测试集只有 4 个文件、2 个家族，R-GCN 的 AUC/EER 不能作为论文结论。它表明工程链路已经打通，并揭示普通攻击训练不能自动解决未见跨 LoD 一致性：测试相关版本最低相似度仍为 0.508。

## 下一步

1. 从开放城市数据中建立至少数百个独立建筑/瓦片，并按城市进行 Train/Validation/Test 隔离；
2. 建立同一对象的 LOD1/LOD2/LOD3 配对，以及 CityGML/CityJSON 配对；
3. 实现严格的 LoD 降级、格式转换和局部城市更新攻击；
4. 增加消融：无关系类型、无语义、无层级、仅点云 KNN、人工特征；
5. 在独立测试城市上报告 ROC、EER、固定 FPR 下的 TPR 和异源尾部。
