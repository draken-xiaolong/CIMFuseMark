# 香港 CIM 数据可用性说明

截至 2026 年 8 月的公开检索，没有发现可以明确归属于李茂栗老师团队、同时提供原始 CIM 三维模型下载的数据集。若老师拥有课题组内部香港 CIM 数据，应先确认格式、许可、可发表范围和脱敏要求，再作为独立测试集接入。

目前可确认的公开香港数据包括：

1. 香港地政总署三维数码地图：2025 年 3 月已覆盖全港，包含建筑、基础设施、植被、场地、水体、地形等对象；公开下载格式主要包括 3DS、FBX、MAX 和 VRML，需要新增格式适配及语义映射。
2. CIM-WV：由香港写实 CIM 渲染得到的 2,000 张二维语义分割图像，不包含可直接用于本项目构图的原始 CIM。
3. HRHD-HK：香港高层高密度场景语义点云，可用于仅几何/点云基线，但不能替代对象层级明确的 CityGML。

建议向李老师索取一个最小样例，并询问四点：文件格式及版本、是否含稳定对象 ID、是否含建筑—构件层级/类别、是否允许公开派生特征和实验统计。项目后续应提供一个统一导入接口，将香港数据转换为当前 `CIMGraph`，而不是要求原始数据公开进入 Git。
