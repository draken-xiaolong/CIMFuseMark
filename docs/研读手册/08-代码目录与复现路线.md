## 2. 核心模块与职责

| 文件 | 做什么 | 输入 | 输出 |
|---|---|---|---|
| `citygml_graph.py` | 解析CityGML并构图、计算节点特征 | `.gml` | `CIMGraph` |
| `rgcn.py` | 张量化、模型结构、固定投影和指纹 | `CIMGraph` | 256维嵌入/1024-bit |
| `xml_attacks.py` | 对完整XML实施攻击 | 原始`.gml`+攻击参数 | 受攻击`.gml` |
| `cityjson_roundtrip.py` | 模拟CityJSON格式往返 | `.gml` | 往返后的`.gml` |
| `robust_losses.py` | 对比、bit稳定、NC、tail和分离损失 | embedding/soft bits | 标量loss |
| `train_robust_contrastive.py` | 最终训练入口 | config+manifest | `.pt`+训练`.json` |
| `evaluate_robustness_curves.py` | 生成攻击强度曲线和异源统计 | checkpoint+manifest | 曲线`.json` |
| `personalize_hash.py` | 冻结编码器后优化登记投影 | Base checkpoint+登记GML | 个性化`.pt` |
| `blend_hash_projection.py` | 混合Base与身份投影行 | 两个`.pt` | Hybrid `.pt` |
| `select_hybrid_fraction.py` | 只用validation选混合比例 | 候选比例+validation | 选择报告`.json` |
| `plot_lite_paper_figures.py` | 生成鲁棒性和唯一性论文图 | 多个结果JSON | PDF/PNG/SVG/TIFF |

## 3. 从数据到论文的复现层级

### 层级A：只理解，不运行

阅读顺序：

1. manifest；
2. `citygml_graph.py`；
3. `CIMLiteGeoFuse`；
4. 最终训练config；
5. 最终曲线JSON；
6. 论文`main.tex`。

### 层级B：读取一个GML并提取图

目标是确认：

- 能找到节点；
- 能看到Building和Surface；
- 能统计边和特征维数。

这一层不需要GPU。

### 层级C：加载已有checkpoint做单模型指纹

读取一个测试GML，加载seed 2026 `.pt`，输出1024 bit。GPU和CPU都能跑；单模型推理很轻。

### 层级D：跑核心攻击评估

使用`--profile core`只跑13个代表攻击点。首次生成受攻击GML较慢；后续可复用attack cache。

### 层级E：完整训练

使用RTX 4090训练2,400轮。需要：

- 47个训练瓦片；
- 攻击文件临时目录/缓存；
- 最终配置JSON；
- 足够运行时间。

## 4. 关键命令模板

以下命令应在仓库根目录执行。

### 训练最终Base

```bash
PYTHONPATH=code python3 code/train_robust_contrastive.py \
  --config code/configs/lgfm_robust_binary_all_cim.json \
  --manifest code/data/plateau_multicity_manifest.json \
  --encoder-type lgfm \
  --feature-mode lgfm \
  --device cuda \
  --seed 2026 \
  --output-prefix lgfm_inspired/cim_lgfm_robust_binary_all_seed2026
```

### 核心攻击评估

```bash
PYTHONPATH=code python3 code/evaluate_robustness_curves.py \
  --manifest code/data/plateau_multicity_manifest.json \
  --checkpoint CHECKPOINT.pt \
  --split test \
  --profile core \
  --device cuda \
  --output core_curves.json
```

### 完整攻击曲线

把`--profile core`改成`--profile all`。完整评估会显著增加XML攻击生成和解析时间。

## 5. `.pt`检查点里有什么

PyTorch检查点通常包含：

- `state_dict`：模型权重及固定投影；
- `relations`：关系词表；
- `config`：训练配置；
- `encoder_type`：当前为`lgfm`；
- `relation_mode`：当前为`typed`；
- `feature_mode`：当前为`lgfm`；
- `training_protocol`：攻击训练说明。

## 6. 哪些代码是历史探索

仓库保留了：

- R-GCN、GCN、GraphSAGE、GAT、关系感知GAT；
- 仅几何、几何+深度、复杂度、尺度、频域特征组合；
- 个性化编码器微调；
- 早期开放集阈值评估。

这些用于消融和探索。最终主线路是：

```text
lgfm特征张量
→ CIMLiteGeoFuse轻量均值图传播
→ 256维嵌入
→ 1024-bit固定投影
→ Base或Hybrid-10
```
