# 07 攻击实验与评价指标

## 1. 攻击实验在测什么

从干净CIM提取指纹`F(M)`，再对完整CityGML XML实施攻击得到`T(M)`，重新解析、构图并提取`F(T(M))`，最后计算二者平均NC。

```text
干净GML -> 指纹A
干净GML -> XML攻击 -> 受攻击GML -> 指纹B
NC = A与B相同比特比例
```

受攻击图无法解析或被删空时按NC=0计算，不从样本中剔除。

## 2. 主鲁棒性大图的12类攻击

| 攻击 | 最大主图强度 | 修改内容 | 主要检验 |
|---|---:|---|---|
| 混合对象删除 | 80% | 随机删除语义对象 | 一般结构缺失 |
| 整栋建筑删除 | 80% | 删除Building及其子树 | 大块内容缺失 |
| 语义表面删除 | 80% | 删除墙/屋顶/地面等 | 局部表面缺失 |
| 属性删除 | 80% | 删除XML属性/叶子属性 | 属性鲁棒性 |
| 坐标噪声 | 0.5%尺度 | 扰动坐标 | 测量误差 |
| 坐标量化 | 0.05 | 坐标舍入 | 精度降低 |
| Z轴旋转 | 180° | 整体旋转 | 刚体不变性 |
| 顺序组合攻击 | 60% | 连续施加多种操作 | 复合攻击 |
| 连续空间裁剪 | 80% | 删除连续空间区域 | 真实裁剪 |
| 层级扁平化 | 100% | 移除/改写父子层级 | CIM结构变化 |
| 语义重标记 | 80% | 更换语义对象类型 | 语义变化 |
| 建筑添加 | 80% | 向模型加入建筑对象 | 增量拼接 |

主图比较方法只包含直接面向CityGML/CIM的算法：

- 本文CIMFuseMark；
- Jiang18零水印；
- Blind-DCT18嵌入式盲水印；
- Octree-QIM19嵌入式盲水印；
- Homograph19嵌入式盲水印；
- CQT22嵌入式盲水印。

点云或普通网格方法不再放进主图，因为研究对象和输入结构不同。

## 3. 额外CIM专项攻击

完整评估还包括：

- LoD2降级为LoD1；
- CityGML到CityJSON再往返；
- 关系边删除；
- 对象顺序重排；
- gml:id重命名；
- 坐标单位转换。

这些攻击不一定都出现在12宫格主图，但用于检查编码、层级和格式变化。

## 4. 为什么强度可以到80%

80%是压力测试，用来观察模型在极端破坏下如何退化。它不意味着删除80%建筑后仍应该无条件认定为原模型。

合理解释应分三层：

- 低强度：常见编辑和噪声，期望稳定；
- 中强度：较大裁剪，观察可用边界；
- 60%—80%：极端压力，必须结合剩余内容量和异源NC解释。

## 5. 鲁棒性指标

### 平均NC

对64个测试tile分别计算同源NC，再求平均。主论文采用“攻击强度—平均NC曲线”。

### q05和最小值

JSON也保存5%分位数和最小值，用于发现平均值掩盖的困难样本，但主图保持简洁，只显示平均NC。

### 有效图率

攻击后仍能成功构图的比例。被彻底删空的样本按失败处理。

## 6. 唯一性指标

64个测试CIM两两组合有：

```text
64 × 63 / 2 = 2,016个异源对
```

对每一对不同CIM计算指纹NC，并报告：

- 异源平均NC；
- 异源q95：95%的异源对不超过该值；
- 异源最大值：最相似的两个不同CIM；
- 完全碰撞数。

1024-bit随机均衡指纹的异源NC理论上接近0.5。当前Base平均约0.631，说明唯一性仍有改进空间。

## 7. 为什么不能只看同源NC

假设一个坏算法对所有CIM都输出全1：

- 受任何攻击后NC都是1，似乎极其鲁棒；
- 但任何两个不同CIM的NC也是1，完全没有身份区分能力。

所以必须同时报告：

```text
同源NC高 + 异源NC低
```

## 8. 相同几何、不同CIM信息实验

为说明CIM方法相对网格几何的意义，项目构造了坐标多重集合完全不变的变体：

- 删除属性；
- 语义重标记；
- 层级扁平化；
- XML对象重排作为不改变内容的控制组。

Jiang18只依赖坐标，对前三类变化分离度都是0；完整CIMFuseMark对属性、语义、层级分别产生0.108、0.097、0.145的身份分离，对纯XML重排保持0。

这说明模型不是只把CityGML当坐标文件，而是能感知部分CIM信息。

## 9. 统计比较

论文在每类攻击最大强度上：

1. 对每个tile做12类攻击宏平均；
2. 与每个baseline进行逐tile配对；
3. 使用单侧Wilcoxon符号秩检验；
4. 对五个比较做Holm多重校正；
5. 用10,000次配对bootstrap计算平均差95%置信区间。

本文相对Jiang18的宏平均NC提高约0.046，95%区间为[0.028, 0.062]。
