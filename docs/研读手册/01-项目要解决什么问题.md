# 01 项目要解决什么问题

## 1. 什么是CIM

CIM可以简单理解为“带有城市知识的三维模型”。普通三维网格通常只告诉我们顶点、三角形和表面长什么样；CityGML形式的CIM还会告诉我们：

- 哪些面属于同一栋建筑；
- 哪些是屋顶、墙面、地面、门或窗；
- Building、BuildingPart、BoundarySurface之间是什么层级；
- 对象有哪些属性和标识；
- 不同对象在空间上是否邻近。

因此，CIM的版权对象不只是“看起来一样的三维外壳”，还包括可查询、可分析的语义结构。

## 2. 为什么不直接使用传统三维网格水印

CityGML当然可以转成OBJ、STL等三角网格，然后使用传统网格水印。但转换可能丢失：

- 屋顶、墙面、地面等语义标签；
- Building与Surface之间的层级；
- 属性、ID和对象关系；
- 不同LoD之间的结构信息。

如果保护目标只是可见形状，网格水印已经可以工作；如果保护目标是完整CIM资产，就需要直接在原生CityGML的“几何—语义—关系”上定义身份。

## 3. 什么是零水印

### 嵌入式水印

嵌入式水印会修改原始载体，例如轻微移动顶点、修改坐标小数位或改变频域系数，把秘密比特写进去。

### 零水印

零水印不修改原始CityGML。它执行三步：

1. 从CIM内容提取一个稳定二值指纹；
2. 将该指纹与所有者版权标识按位异或，生成登记证据；
3. 发生版权争议时，再从待测CIM提取指纹并恢复/验证版权标识。

可把它类比为“用内容生成身份证号码”，而不是在建筑模型上刻字。

## 4. 本项目的核心问题

设原始模型为`M`，受攻击版本为`T(M)`，另一个模型为`N`。我们希望：

- `fingerprint(M)`与`fingerprint(T(M))`尽量相同；
- `fingerprint(M)`与`fingerprint(N)`尽量不同。

这两个要求存在冲突。若模型忽略所有细节，攻击后指纹很稳定，但不同城市也可能长得一样；若模型记住每个细节，不同城市很容易区分，但删除一个属性就可能导致指纹完全变化。

所以本项目不是单纯追求最高NC，而是在以下两者之间取平衡：

- **鲁棒性**：同源模型受攻击后仍能认出来；
- **唯一性**：不同模型不能频繁产生相似指纹。

## 5. 输入与输出

### 输入

- 文件格式：`.gml`，本质上是XML文本；
- 内容：CityGML建筑对象、坐标、表面、属性和层级；
- 训练时：一个干净GML加三个随机攻击版本。

### 中间结果

- CIM语义图；
- 每个节点31维信息；
- 整个图的256维向量表示。

### 输出

- 一个长度为1024的二值指纹，例如`011010...`；
- 指纹保存在模型评估JSON或登记系统中，不写回原始GML。

## 6. 当前论文真正可以支持的结论

- 可以说：提出了直接面向CityGML/CIM的学习式图零水印框架。
- 可以说：在日本PLATEAU跨城市数据上，对多类几何、语义和结构攻击具有较好平均NC。
- 可以说：模型很轻，只有79,857个可训练参数。
- 不宜说：关系图一定比不使用边更好，因为消融实验中no-edge在平均NC上并不差。
- 不宜说：80%删除后仍一定属于原模型；80%删除只是压力测试。
- “首次将GNN用于CIM零水印”在正式投稿前仍应以系统文献检索结果为准。
