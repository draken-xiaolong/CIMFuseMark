# 香港实景三维数据下载审计

## 2026-08-21初步结果

- 官方入口：`3D Visualisation Map API`；
- 根tileset：`https://data.map.gov.hk/api/3d-data/3dtiles/f2/tileset.json?key=...`；
- 根索引包含17个一级区域；
- 初步递归前三层发现2,263个后续JSON索引和至少1,021个中间LoD payload；
- 对15个地理分区抽取852个`.b3dm`执行HEAD：
  - 平均267,351 bytes；
  - 中位数171,618 bytes；
  - 90%分位754,296 bytes；
  - 最大1,941,416 bytes；
- 根据子索引内payload数量分层外推，原始全港3D Tiles约28 GB。

## 容量规划

28 GB只是元数据树抽样估计，正式规划应包含：

| 内容 | 建议预留 |
|---|---:|
| 原始3D Tiles | 50 GB |
| 转换GLB/PLY/OBJ | 50–150 GB |
| 训练切片、攻击缓存 | 100–200 GB |
| 模型、结果和临时空间 | 20–50 GB |
| 总预留 | 200–400 GB |

移动硬盘`/Volumes/SANDISK-ELE`总容量约1.8 TiB，当前可用约1.4 TiB，可以支持。

## 正式下载前置条件

1. 使用个人`HK3D_API_KEY`，不使用官方文档演示key做全港批量下载；
2. 生成完整URL、Content-Length和SHA-256状态清单；
3. 下载器支持断点续传、失败重试、低并发和重复URL去重；
4. 保存官方使用条款快照和数据来源说明；
5. 原始文件只落在移动硬盘，不进入Git。
