# 带纹理香港城市样例

## 为什么第一个样例像白色碎石

第一个样例位于植被/海岸区，并且转换 OBJ/PLY 时没有解码 KTX2
摄影纹理。这不代表 Open3Dhk 数据只有地形。

## 城市样例

样例中心位于约 `114.145E, 22.282N`，与李老师 CIM-WV 图像中的一组
香港岛窗景坐标接近。它由四个相邻的精细 B3DM 瓦片组成：

- `Tile_109_52_L1.b3dm`
- `Tile_110_52_L1.b3dm`
- `Tile_109_53_L1.b3dm`
- `Tile_110_53_L1.b3dm`

转换结果位于：

`/Volumes/SANDISK-ELE/HKReal3DMarkData/viewer_samples/HK_urban_limaosu_4tiles`

### MeshLab

优先打开 `HK_urban_limaosu_4tiles.glb`。该文件的 KTX2 已转为普通 PNG
纹理并内嵌到 GLB。如果 GLB 加载异常，打开
`meshlab_obj/HK_urban_limaosu_4tiles.obj`，不要移动同目录的 MTL 和 PNG。

### CloudCompare

打开 `HK_urban_limaosu_4tiles.ply`。PLY 主要用于几何、点云、裁剪、降采样、
配准和距离比较，不以照片纹理为主。

### 浏览器

目录中的 `view.html` 是交互预览页。由于浏览器对本地模型请求有
安全限制，建议在该目录执行：

```bash
python3 -m http.server 8000
```

再访问 `http://127.0.0.1:8000/view.html`。

## 转换脚本

`code/export_b3dm_compatible.py` 从 B3DM 中提取 GLB，调用 Basis Universal 解码
KTX2，并输出 MeshLab 可读的 `model.gltf + model.bin + texture PNG`。

## 与李老师窗景图像的关系

当前样例已证明目标坐标附近存在带纹理高楼模型。要复现一张
900x900 窗景，还需继续下载相机朝向覆盖的瓦片，并完成坐标系、
高程、朝向角和 60 度视场角标定。两版实景模型年份不同，不应预期
与 CIM-WV 原图逐像素一致。
