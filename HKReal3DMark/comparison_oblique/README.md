# 倾斜摄影实景三维水印对比实验

本目录只收录研究载体与香港摄影测量实景三维网格一致的五个基线。所有实验固定
随机种子 `2026`，使用相同地域隔离测试集和相同攻击实现。主指标为攻击强度--平均
NC；嵌入式方法不参与异源内容唯一性排序。

| ID | 论文方法 | 类型 | 复现级别 |
|---|---|---|---|
| `PC-Reversible26` | 法向夹角特征点、局部球坐标半径可逆嵌入 | 可逆嵌入式 | 官方代码适配 |
| `Nan25-Curvature` | 多层曲率、加权距离分组、高差 QIM | 嵌入式 | 论文公式适配 |
| `Nan25-ZW` | 垂向偏度与 SVD 零水印 | 零水印 | 论文公式适配 |
| `Jiao23-Dual` | 聚类质心距离与纹理坐标联合嵌入 | 嵌入式 | 论文公式适配 |
| `Qiu19-RI` | 顶点分组、球坐标半径、QR 富信息水印 | 可逆嵌入式 | 论文公式适配 |

## 公平性约束

1. 每个方法处理同一组 B3DM 中解析出的三角网格；不得用论文原始六个示例模型的
   报告值代替香港测试集实测值。
2. 几何攻击必须作用于嵌入后的网格；零水印方法作用于待认证网格。
3. 所有方法使用同一二值版权图案。若原生容量不同，同时报告原生容量与公共前缀
   NC，不能通过强行扩容降低某个基线表现。
4. `Nan25-ZW` 与本文方法同时报告异源唯一性；四个嵌入式方法该项记为 N/A。
5. 官方实现存在未参数化路径、全局变量和点选择细节，适配时保留算法核心，但修复
   工程错误；所有偏离原代码之处记录在 `ADAPTATION_LOG.md`。
6. 第一轮使用现有 120 模型地域隔离集；分层 payload 下载完成后扩大数据集复验。
